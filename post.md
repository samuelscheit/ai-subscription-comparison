We should stop comparing the value of AI subscriptions based on the number of tokens or API credit equivalent and instead consider the number of (comparable) tasks that can be accomplished per subscription.

https://x.com/scaling01/status/2107207614115594391?s=20

---

Token counts alone don’t tell you how much work you can actually get done

Two subscriptions with the same amount of tokens can deliver very different value because models need different numbers of tokens to complete the same task successfully

---

API-equivalent value is arbritrary and depends on the provider's api pricing/margin

If a provider offers a subscription with 50x its API-equivalent value, it has great relative value compared to paying API prices

However you are not paying API prices and never would for coding

---

Consider ArtificialAnalysis.ai Intelligence vs task cost

To achieve a task with a needed "intelligence level of 51" you would either need to use

- GPT 6.1-Sol xhigh and pay $0.39 or
- Opus 5.5 medium and pay $1.34

---

Now consider SemiAnalysis's API value by plan

- Claude Max 20x costs $200/mo | grants $11.726
- ChatGPT Pro 20x costs $200/mo | grants $2.084

---

Claude Max $11.726 / $1.34 per task = 8.750 tasks
ChatGPT Pro $2.084 / $0.39 per task = 5.343 tasks

---

Of course this is simplified, because not all tasks are equally hard and api credits per plan are dependent on the token usage (input vs cached vs output)

However, this way of looking at them still gives you a way better estimate on actual real world value of the subs for coding
